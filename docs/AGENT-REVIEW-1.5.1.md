# Release review: Web QA Assistant 1.5.1

## Product lens
Preserve the full 1.5.0 product redesign. Prioritize trust, multi-discipline usefulness, and evidence-led Frank recommendations over adding scanners.

## QA lens
The exact screenshot regression must be exercised through the runtime semantic pipeline, not a handcrafted recommendation object. Performance collection must be tested at its browser API boundary.

## Security lens
Outbound AI payloads must be constructed from explicit allowlists. Nested URLs and structured performance evidence must receive the same query sanitization as top-level URLs. Test fixtures must remain synthetic.

## Engineering lens
Release metadata must be derived/validated against the package version, and the renderer and extension should share the same classifier/performance behavior wherever applicable.
