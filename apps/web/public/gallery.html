Lumen state gallery

Every state of every surface, rendered from the stylesheets that ship. The first half puts the four surfaces beside each other, because that is where the drift is: the overlay, the side panel, the web app and the exported report each draw the same ideas with their own mechanism, and in the product they are never on screen at the same time. The second half is the overlay's own states, ordered by how hard a state is to reach in a real audit rather than by how common it is.

Each surface renders in the context it really renders in: the overlay in a shadow root under an inline all:initial, the three document surfaces in iframes, because their sheets style html and body and a shadow root would silently drop those rules. Run npm run build:extension first; this page reads what that build emitted.
